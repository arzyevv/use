Use

A minimal browser for macOS. The page gets the whole window; everything else stays out of the way.

Download for Mac

Apple Silicon · macOS 15.4 or later · Free

From the download

Drag Use to Applications and open it. macOS blocks it the first time: allow it once in System Settings ▸ Privacy & Security ▸ Open Anyway.

From Terminal

Installs and opens Use, with nothing to allow.

curl -fsSL https://arzyevv.github.io/use/install.sh | sh

Updates are built in: Use ▸ Check for Updates.
